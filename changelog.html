RELEASE NOTES

Changelog

What changed in each release. The newest version is always the one the download button gets you.

0.7.2

2026-11-18
  • Session and clip fixes on every capture mode (window, monitor, exclusive fullscreen): no cut tails, no overshoot on stop, and clips on still windows no longer start far back.
  • The save log shows the seconds requested.

0.7.1

2026-11-17
  • Audio preview delay fix.
  • 10-minute limit for added video, GIF and sound; delete button on timeline items.
  • Faster Spotify and app detection; Discord status only while clipping.
  • Stays attached to the game when you alt-tab (window and fullscreen capture).
  • Crash fix: panics are now caught and logged.

0.7.0

2026-11-14
  • Desktop Duplication capture for exclusive-fullscreen games (Minecraft and the like).
  • Capture method picker: Auto, Desktop Duplication or Windows capture.
  • Recorder GPU priority setting.

0.6.5

2026-11-14
  • New dark installer, also used for in-app updates.
  • Fixes a false “update available” on fresh PCs.
  • Editor, mixer and audio improvements.
  • Archy.zip: installer plus a Portable folder, offline, with FFmpeg and voice included.

0.6.4

2026-11-13
  • CapCut-style editor: drag the Order blocks to rearrange parts, and a Snap toggle (magnets for parts, items and the playhead).
  • Media imports can be as long as the clip you're editing; the trim popup asks you to pick the right part.
  • Per-app audio tracks with a game-only track 1; mixer volumes no longer mute off 100%.
  • Speed-up audio preview, visible resize handles on drawings and images, track names saved in session files.

Older versions and full notes are on the GitHub releases page.
