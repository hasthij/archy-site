HOW IT WORKS

Three steps. One key.

  1. 0101

    Open a game

    Archy starts keeping the last moments as soon as a game from your list is open, and stops when it closes. Nothing runs the rest of the time.

  2. 0202

    Hit F8, or just say it

    The last 30 seconds (or 60 with Shift+F8) are saved as an MP4 in well under a second. Or say “Archer, clip that”.

  3. 0303

    Trim it, send it

    It's already on your clipboard. Or open it in the editor first, cut it down, add text or music, and export a video, GIF or MP3.

QUESTIONS

FAQ

Is it safe with anti-cheat?

Archy never injects anything into a game. It records with Windows' own capture (Windows Graphics Capture, or Desktop Duplication for exclusive-fullscreen games), which reads the picture from the outside, so it's safe to run alongside anti-cheat.

Will it slow my game down?

Barely. Archy encodes on the graphics chip's own video engine instead of the parts that draw your game, keeps to efficiency cores at low priority, and records nothing when no game is open. Measured in Roblox on an Intel iGPU, the cost was about 2–3% FPS.

Does it work with fullscreen games like Minecraft?

Yes. The capture method is set to Auto: exclusive-fullscreen games are recorded with Desktop Duplication, everything else with Windows Graphics Capture. You can force either one, and Archy suggests switching if a game's clip freezes or the cursor is missing.

Where do my clips go? Does it upload anything?

Clips are saved to Videos\Archy as ordinary MP4 files (you can pick another folder). Nothing is uploaded and there's no account; voice clipping runs on your PC too. The only network use is an optional update check against GitHub.

Why does Windows warn me about the installer?

The installer isn't code-signed. A code-signing certificate costs hundreds of dollars every year, which is a lot for a free hobby project, so Windows SmartScreen doesn't recognise Archy yet and may show “Windows protected your PC”. Click More info, then Run anyway. If the exe is blocked or deleted anyway, get the zip: it holds the installer plus a portable folder (run archy.exe, no install). Only download Archy from its GitHub releases; the full source is there too, so you can read it or build it yourself.

Is it really free?

Yes. Archy is open source under the GPL-3.0 licence. No ads, no subscription, no account. The code is on GitHub.
